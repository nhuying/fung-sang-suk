# ฟังสร้างสุข (Joyful Listening)

เว็บแอป Deep Listening ธีม "The Cozy Campfire"  
ช่วยให้กลุ่มเพื่อน/ครอบครัว/ทีมงาน ฟังด้วยหัวใจ ลดช่องว่าง สร้างความสัมพันธ์ที่ดี

## คุณสมบัติหลัก
- สร้างห้อง + เข้าร่วมด้วย QR Code (สแกนจากมือถือได้ทันที)
- 4 ระยะตาม Theory U (Hello → Listen → Learn → Empathy)
- Timer + Speaker + Active Listener อัตโนมัติ
- มอบของขวัญทางใจ + Confetti + เสียงกองไฟ
- PWA (ติดตั้งบนมือถือได้) + Offline Mode
- Aura ของกลุ่ม + สรุปผลแบบสนุก

## วิธีใช้งาน
1. เปิด https://ชื่อคุณ.github.io/ชื่อ-repo/
2. กด "สร้างห้องใหม่" บนคอมพิวเตอร์
3. แสดง QR Code → เพื่อนสแกนด้วยมือถือ
4. เริ่มวงสนทนาได้เลย!
